# Bee developer experience: public friction summary

Prepared 18 October 2026 from observations recorded 7–25 September 2026 while building Ringfence. Environment at observation time: macOS, Node 26.7, `@beeai/cli` 0.7.3. Historical observations have not been re-tested against the current Bee service in this audit.

This is a curated publication-safe summary, not the original log. It omits transcripts, conversation IDs, personal names, workplace topics, locations, credentials and raw capture files. F-numbers refer to the original local evidence. The last two entries come from the dated testing notes and README rather than new device tests.

## What worked

The stream captured enough context to prototype the workflow, Bee's semantic summaries helped agents understand a request, webhooks were useful, and todos plus the changefeed provided a viable human approval channel. The two upstream CLI changes are contributions from the build; neither was merged when checked on 18 October 2026.

## Scope of the claims

These are dated observations from one developer and device setup. They do not establish current service-wide defect rates, language accuracy or watch compatibility. A classifier score above a threshold does not prove that hostile media can never trigger an agent. Ringfence's own host-execution and privacy limits are documented in the README and audit report.
